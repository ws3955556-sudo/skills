## 🚀 快速开始

### 方法一：安装 Skill（推荐在 WorkBuddy 中使用）

1. 下载对应的 `.zip` 文件
2. 在 WorkBuddy 的 Skill 管理中选择「导入本地 Skill」
3. 选择 zip 文件完成安装
4. 安装后会根据 frontmatter 中的触发词自动激活

### 方法二：使用独立 Prompt 文件

1. 下载对应的 `Prompt.md` 文件
2. 将文件内容完整复制到任意支持系统提示词的大模型（如 Claude、DeepSeek、ChatGPT 等）
3. 文件已包含完整的角色定义、教学风格、回答模板和安全约束
4. 直接开始对话即可

## 🧠 教学特色

### 1. 三层回答结构

每个概念都按以下三层组织，小白友好：

- **第一层：生活化比喻** —— 先让小白有画面
- **第二层：官方定义** —— 再给出准确的专业解释
- **第三层：结合实际场景** —— 最后落到真实场景和常见误区

> 示例：讲防火墙
>
> - 比喻：小区门卫，按规则表检查进出车辆
> - 定义：部署在网络边界，依据策略控制流量的安全设备
> - 场景：装了防火墙不等于万无一失，它查"车"不查"车里装什么"

### 2. 双模式切换

| 模式         | 触发方式                   | 回答特点                         |
| ------------ | -------------------------- | -------------------------------- |
| 日常问答模式 | 默认，问"是什么""有什么用" | 3-5 句话，比喻 + 定义 + 要点     |
| 深度教学模式 | 说"详细讲""怎么做""做实验" | 完整展开，含攻防双视角或实验步骤 |

### 3. 小白优先原则

- 每个专业术语第一次出现必须配一句人话解释
- 不堆术语、不报菜名
- 复杂内容分块讲解，讲完一块确认一次
- 安全设备全部拟人化（防火墙 = 门卫，WAF = 防弹玻璃，SIEM = 指挥中心）

### 4. 紧急问题优先

当用户描述正在发生的安全事件（如"电脑中毒了""文件被加密""账号被盗"），会自动跳过教学模板，先给处置步骤：

1. 先稳住（断网/隔离）
2. 处置步骤（按优先级）
3. 不要做什么（禁忌清单）
4. 事后保存证据
