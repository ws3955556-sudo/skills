## 🧠 教学特色

### 1. 三层回答结构

每个概念都按以下三层组织，小白友好：

- **第一层：生活化比喻** —— 先让小白有画面
- **第二层：官方定义** —— 再给出准确的专业解释
- **第三层：结合实际场景** —— 最后落到真实场景和常见误区

> ⚠️ **输出顺序说明：** 日常问答模式比喻在前（先有画面再看定义），深度/实战模式定义在前（先立骨架再填血肉）。三层是知识范围，不是固定顺序。

> 示例：讲防火墙
>
> - 比喻：小区门卫，按规则表检查进出车辆
> - 定义：部署在网络边界，依据策略控制流量的安全设备
> - 场景：装了防火墙不等于万无一失，它查"车"不查"车里装什么"

### 2. 双模式切换

| 模式               | 触发方式                         | 回答特点                                 |
| ------------------ | -------------------------------- | ---------------------------------------- |
| 日常问答模式       | 默认，问"是什么""有什么用"       | 3-5 句话，比喻 + 定义 + 要点             |
| 深度/实操/实战模式 | 说"详细讲""怎么做""做实验""排查" | 完整展开，含攻防双视角/实验步骤/排查流程 |

### 3. 小白优先原则

- 每个专业术语第一次出现必须配一句人话解释
- 不堆术语、不报菜名
- 复杂内容分块讲解，讲完一块确认一次
- 安全设备全部拟人化（防火墙 = 门卫，WAF = 防弹玻璃，SIEM = 指挥中心）
- 触发词覆盖口语表达（"抓包是什么""电脑很卡""被黑了"等）

### 4. 紧急问题优先

当用户描述正在发生的安全事件（如"电脑中毒了""文件被加密""账号被盗"），会自动跳过教学模板，先给处置步骤：

1. 先稳住（断网/隔离）
2. 处置步骤（按优先级）
3. 不要做什么（禁忌清单）
4. 事后保存证据

> 应急响应助手特有的**黄金 5 分钟处置结构**：1 句话告诉当前最该做什么 → 按优先级排列步骤 → 明确禁忌 → 保存证据 → 最后才讲原理。

### 5. 零基础入门路径

每个 Skill 都内置了零基础引导：当用户问"是什么""怎么学""从哪开始"时，不会一次性倒完所有知识，而是先给 3 个核心概念让用户选方向。

## 🔧 各 Skill 详细说明

### 1. 红蓝对抗教学（cyber-red-blue-teaching）

**定位：** 用比喻和双视角把攻防概念讲透

**核心内容：**

- 攻击链八步曲（入室盗窃比喻）
- 防御七层体系（城市防御比喻）
- 12 类安全设备拟人化
- 攻防对照三档拦截等级

**参考文件：** 红队攻击链 · 蓝队防御体系 · 安全设备拟人化 · 攻防对照表

### 2. 网络安全实验助手（cyber-lab-assistant）

**定位：** 手把手带小白在靶场里做实验

**核心内容：**

- 8 个经典实验分步指引（SQL 注入/XSS/文件上传/命令注入/CSRF/文件包含/暴力破解/提权）
- CTF 六大方向方法论（Web/Crypto/Pwn/Reverse/Forensics/Misc）
- 靶场环境搭建指南（DVWA/Metasploitable/WebGoat/Juice Shop/VulnHub/Docker）
- 安全合规红线 + 报错排查模板

**参考文件：** 实验指南 · CTF 方法论 · 原理速查 · 靶场搭建 · 安全规则

### 3. 安全工具精通助手（cyber-tool-master）

**定位：** 帮小白从零掌握安全工具的用法

**核心内容：**

- Web 工具：Burp Suite 全模块、OWASP ZAP、sqlmap、Nikto、目录扫描工具
- 网络工具：Nmap 全参数 + NSE、Wireshark 过滤器、Masscan、tcpdump、Aircrack-ng
- 漏洞利用工具：Metasploit + Meterpreter、Cobalt Strike、BloodHound、Mimikatz
- 取证密码工具：Volatility、Autopsy、John/Hashcat、Ghidra/IDA、foremost/binwalk
- 工具学习方法论：三阶段路线图、选型决策树、4 套组合拳、操作 checklist

**参考文件：** Web 工具 · 网络工具 · 漏洞利用工具 · 取证密码工具 · 工具学习方法论

### 4. 应急响应实战助手（cyber-ir-assistant）

**定位：** 安全事件发生后告诉用户"先做什么、再做什么"

**核心内容：**

- 应急响应六阶段流程（准备→检测→遏制→根除→恢复→复盘）
- Windows 应急排查全流程（进程/网络/启动项/服务/日志/账号/文件）
- Linux 应急排查全流程（进程/网络/crontab/日志/账号/文件/Rootkit）
- 7 大攻击场景处置（勒索/挖矿/Webshell/数据泄露/钓鱼/DDoS/横移）
- 四大取证分析（日志/内存/磁盘/网络）+ 时间线还原 + IOC 提取

**参考文件：** 应急流程 · Windows 排查 · Linux 排查 · 攻击场景处置 · 数字取证分析

### 5. AI×安全交叉研究（cyber-ai-research）

**定位：** 讲 AI 与网络安全交叉领域的前沿研究

**核心内容：**

- AI 赋能安全：ML 威胁检测、智能安全分析、自动化响应、AI Fuzzing、NLP 安全
- 安全赋能 AI：对抗样本全解、模型投毒与后门、模型窃取、隐私攻击、LLM 安全全景
- 研究方法论：选题评估、经典论文索引、数据集资源、实验设计框架
- 经典案例与趋势：DeepLocker、MITRE ATLAS、Garak、自动驾驶对抗攻击等

**参考文件：** AI 赋能安全 · 安全赋能 AI · 研究方法论 · 案例与趋势
